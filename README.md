# VibeNode

VibeNode enables real-time data processing, leveraging cloud-based services as a high-performance, horizontally scalable data server orchestrator.

VibeNode is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/VibeNode.git`
2. `cd VibeNode`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure VibeNode, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
